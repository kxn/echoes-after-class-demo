# 角色、步行、脚步与朝向受光修订

- 男 1：软军帽、军绿色上衣和长裤；女 2：军绿帆布斜挎包；女 4：短直齐耳发。
- 重新使用 H3 fl2va 生成步行视频，选择 27 帧循环。整个视频只应用同一个亚像素变换，去掉旧版逐帧脚底/躯干吸附造成的位置跳动。运动和镜头、动画共用渲染时钟。
- 脚步替换为 Kenney CC0 硬地面录音，经过频段限制、柔化起止和音量调整；来源及许可见 `assets/audio/LICENSE.md`。这不是历史布鞋的实地录音。
- 落脚帧为 0、13，运行时按行走距离跨过帧边界触发，不再按独立的步长计数或计时器播放。没有行走位移就不触发。
- 朝右允许窗光作用于脸与前身；朝左禁用局部窗光，只保留人物底图和缓慢的空间曝光变化。两种朝向都继续投影到桌面。
- 修正右侧一张前排桌面向右倾斜的透视遮挡，避免角色腿部穿到桌面前方。

## 验证

Godot 4.7.2 / Compatibility / RX 5700 XT。523 项逻辑断言通过，60 项素材与截图检查通过。

10.5 秒、60 fps 游戏原生录制含 16 次落脚和 16 次声音；在未压缩音轨中，以幅度阈值 0.0008 检测的声音起点比落脚事件晚 2.3–10.4 ms，低于一个录制帧。末尾站立期间没有额外脚步。实际声卡/蓝牙播放延迟不包含在这项测量里。

固定镜头分别拍摄左右朝向、窗光开关四张图。人物脸与上身采样框 `(570,315)-(650,450)`：朝左开关差值为 0，朝右平均绝对差约 10/255。数据见 `runtime-validation.json`。

`walk-audio.mp4` 是含音轨的实际游戏录制；`walk-loop.gif` 是透明帧在灰底上的循环检查图，金点仅标注落脚帧，不会出现在游戏里。生成式序列仍有布料细节的轻微变化，未采用逐帧拉伸或强制锁定头部消除自然步态。

## 复现

1. `tools/submit_walk_revision2.py` 提交 H3 请求；已有完整请求、视频及结果时无需重复提交。
2. `tools/build_walk_revision2.py --start 28 --end 55 --contacts 0,13` 生成当前循环及法线图。
3. `tools/extract_painted_layers.py` 更新桌椅原像素层、人物响应和柔影轮廓。
4. `tools/prepare_footsteps.py` 从已保存的 CC0 原素材生成脚步。
5. Godot 导入后，`-- --test` 检查逻辑，`-- --capture` 重拍原画/投影对照，`-- --revision-capture` 重拍朝向对照。
6. `--fixed-fps 60 --write-movie docs/revision2/walk-audio.avi -- --walk-demo` 录制含音轨的步行，同时输出落脚时间线。转为 MP4 时保留音轨。
