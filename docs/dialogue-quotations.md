# 对话开场语录

按场景创作要求，为三名 NPC 的首次、重复对话及窗边结尾各加一句开场；不是给每一句往返对白都加前缀。开场是角色按习惯背诵，接着直接进入原有神秘对白。

- 沈禾的点名簿对话与主角结尾：毛主席教导我们——“没有调查，没有发言权。”原句核对：[国家统计局](https://www.stats.gov.cn/zs/tjlshi/jd/202301/t20230101_1903944.html)，对应《反对本本主义》。
- 周槐生的钟声对话：“星星之火，可以燎原。”原句及文章核对：[最高人民检察院](https://www.spp.gov.cn/spp/dsxxjy/202104/t20210423_530295.shtml)。
- 唐小满的借书对话：“好好学习，天天向上。”题词核对：[教育部](https://hudong.moe.gov.cn/jyb_xwfb/moe_2082/zl_2017n/2017_zl20/201703/t20170330_301518.html)。

这些材料用于核对引文，不将“所有人在所有场合都如此开场”当作史实结论。具体场景与人物行为属于本作虚构。
