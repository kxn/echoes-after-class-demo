# 原型验收记录

环境：Windows，Godot 4.7.2 普通版，OpenGL Compatibility，AMD Radeon RX 5700 XT。

- 资源导入和 GDScript 加载成功，无解析错误。
- `tests/smoke.gd` 通过 474 次检查（含沿路径逐步验证），结果见 `test-results.json`。
- 覆盖：左右端换排、中间禁止跨桌、自动寻找较近端点、不同通道禁止交谈、逐字显示、取消后不授予线索、任意顺序收集、重复交谈不重复授予、窗边结尾、镜头边界、迎光强度变化。
- 键盘测试通过真实 Viewport 输入分发，涵盖逻辑 E 和物理 Space 按键；每次松键使用独立事件。
- 通过原生游戏窗口实际点击沈禾，确认角色走近后自动交谈；通过 E 切换至许知秋发言；通过 Tab / Esc 打开、关闭随记。
- 四张截图由 Godot 真实渲染视口保存。检查了靠窗通道、后排通道、说话者头顶对白、桌椅遮挡与右侧夕阳。
- 已修正：不同桌椅图块按宽度缩放造成的桌面高度不一致；键盘逻辑键与物理键兼容。

这是可玩的美术与叙事原型。主角为四帧步行，NPC 为待机及转向；还不是完整商业游戏的动画数量，也没有跨次运行存档。
