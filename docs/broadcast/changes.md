# 放学广播与离场

选择操场大喇叭，经窗户传进室内，教室美术不增加室内音箱。

结尾铃声完整响完（3.7 秒）才播出约 38.31 秒广播。保留校园通知的日常措辞：清点人数、结伴离校、值日打扫、明天照常上课。字幕沿用暖纸色像素字、深褐底与细金线。广播期间玩家仍可行走，暂停 NPC 交谈；静音仍正常走时序、显示字幕。

广播结束，周槐生以 135 像素/秒沿靠窗通道走向左侧后门并离场，隐藏交谈图标和动态投影。后门目前仍是静态绘景，尚未制作开门动作。沈禾和唐小满保留交互，分别否认多出的名字、将明天借书改口为昨天还书；原有线索保留。

## 音频制作

原创虚构广播稿；Windows 本机 Microsoft Huihui 普通话合成语音，不是历史录音，也未克隆个人声音。`tools/make_school_voice.ps1` 生成分句干声，`tools/process_school_broadcast.py` 合成最终音频与字幕时间点。

420–2700 Hz 带通、轻微饱和、弱颤动、105/218/365 ms 多重弱反射、低电平带限底噪和电源嗡声。最终峰值 0.72，游戏内 -10 dB。脚步仍取现有 CC0 布鞋/硬地素材，按周槐生新动画第 5、18 帧触发，并随与主角距离衰减。

## 运动素材

H3 `job_6aa8ba39_00000000`，fl2va，384×640，56 帧，源视频 `assets/animation/npc-exit-v1/video.webm`。使用第 23–48 帧，共 26 帧循环。全段共享亚像素缩放/平移，避免逐帧锚定抖动。步幅 1.9 世界单位，与位移同步采样。保留灰衣、书本、原角色比例；朝左不叠加窗格局部增亮。

脚本 `tools/build_npc_exit.py --start 23 --end 49 --contacts 5,18` 与 `tools/build_npc_masks.py` 重建图集、法线、响应图和柔边影子。

## 验证

- 原有 540 项逻辑断言通过。
- 新增广播测试通过（1114 次断言，包含逐步路线采样）：真实结尾触发、铃声等待、单次触发、静音字幕、交谈优先级、NPC 动画、路线、离场隐藏及两套后续对白。
- 重拍渲染对照后，69 项素材/渲染检查通过。
- 广播播放时实测 3840×1984：平均帧时 16.666 ms，P99 16.821 ms（约 60 FPS，当前机器）。
- `full.mp4` 为完整实录；`preview.mp4` 为开头 10 秒加结尾 20 秒的剪辑，中间广播省略。字幕截图 `announcement.png`，离场 `departure.png`，新对白 `changed-dialogue.png`。
