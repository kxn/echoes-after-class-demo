# 站位、起停过渡、眨眼与墙角补全

唐小满从前排 x=1830、y=960 移到靠窗通道 x=1505、y=840，站在较远一排桌椅之间的空隙，保留原来的身高和体型。当前截图为 `docs/painted/04-tang-placement.png`。

右侧书柜及地球仪替换为扫帚、旧棉条拖把、铁皮桶与簸箕，保留左后门、讲台和通道。当前整景为 `assets/painted/classroom_composite_v4.png`；完整生成结果同时复制为运行时的 `classroom_composite.png`，桌椅切片仍来自同一张图。

## 起步与收步

H3 首尾帧视频任务 `job_6aa8b325_00000000`：384×640，22 帧，fl2va，28 steps。首图来自当前侧身步行接触姿态，尾图是现用斜身站姿。视频前七帧构成收步和转肩过程，最后拼接精确的原站姿，共八帧。没有用两幅整个人像叠加淡入淡出的方式代替转身。

释放行走后用 0.24 秒播放收步；起步以 0.14 秒反向经过过渡姿态，位移立即响应输入。再次按方向键可立即打断收步。左右方向镜像一致。过渡同步使用独立法线、受光响应及透明轮廓，桌面阴影也随过渡变化。脚步仍按行走接触事件触发，站稳不新增脚步。

当前使用一段共用起停过渡，尚未按每一种任意步行相位分别制作收脚分支。

## 眨眼

由内置 image_gen 生成闭眼版本，只提取眼部区域，保留原身体和透明轮廓。运行时不重新生成贴图。四个人首次眨眼错开，之后间隔在 3.5–6.8 秒变化；每次约 0.17 秒（闭眼 45 ms、停留 40 ms、睁开 85 ms）。行走及起停过渡期间暂缓眨眼，避免将站姿眼部贴到侧身脸上。间隔是本作的视觉节奏选择，不宣称来自原作测量。

## 原作视频核对的限制

已找到并打开 [PlayStation 官方实机演示](https://www.youtube.com/watch?v=QQ3zF_lOIv0)，浏览器确认作者为 PlayStation，但播放器提示“请登录，以便我们确认你不是聊天机器人”，因此没有可靠观看到逐帧内容。未据此声称已经测得原作的具体帧数、眨眼频率或完整状态机；本次实现按用户描述和本项目素材进行设计。
