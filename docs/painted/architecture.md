# 绘画主导的夕阳教室

当前入口为 `scenes/classroom_painted.tscn`。用户要求保留场景绘画光照，桌椅和场景同时绘制后拆层；人物局部动态增亮，并在桌面投出沿夕阳方向拉长的柔边影子。

## 光源与分工

动态方向光代表窗外太阳，编辑参考位置 `(20,12,-16)`，传播方向 `normalize(-0.45,-0.52,1)`：从窗外右后方向室内左下方射入。DirectionLight 由方向决定入射，而非上述位置决定衰减。当前没有室内补光，全局环境光能量为零。静态教室亮暗由画决定；灯泡在画中熄灭。

旧试验把室内改成中性底图，再用均匀环境光和几何照亮，这损失了原画的反光、体积和情绪。当前整景重新连同桌椅一起绘制，桌面金边、窗框反光、桌下冷暗、地面光斑保持在同一张图里。静态场景使用 unshaded 材质。关掉动态太阳不会把这张画变平。

## 层与人物

完整绘画作为底层。14 张桌椅遮挡片直接复制原图 RGB，按前后排给定深度；中间和窗边通道各有不同的角色深度。桌椅固定在画中的位置，不做独立平移，因此完整底画无须另行修补。遮挡轮廓和桌面四角在 `assets/painted/layers.json`，目前为人工标定的多边形。

角色底图保留自身衣褶和面部明暗，shader 将其作为固定底色输出；动态方向光只增加选定部位的暖光。辅助法线从轮廓距离场与低幅度衣褶变化近似得出，响应图区分头发/肩部、衣袖/手部和较少受影响的裤装。法线不是准确的人体或布料三维重建。转身同时翻转颜色、法线横轴和投影轮廓。窗洞与窗框的不可见几何阻挡人物动态光。

## 桌面柔影

桌面四边形在正交镜头下与原画像素位置吻合，同时具有从远端到近端的深度。它仍采样原画的颜色，仅额外计算人物投影。

对桌面像素 P，人物面片深度 z_i，太阳传播方向 d：

```
t = (P.z - z_i) / d.z
Q = P - t * d
```

t > 0 时，将 Q 映射回角色面片 UV，采样当前动画帧的透明轮廓。桌面深度变化自然使轮廓沿低角度夕阳拉长。采样使用当前帧、当前位置、朝向和深度，三位 NPC 也参与。离人物更远的部分增加采样半径，加上轮廓预模糊形成柔边。

最终将原画中的受光部分乘上有上限的冷暗色。未投影处保持原画值，不额外增亮；桌前挡板与墙面不参与这一接影处理。R 单独开关投影，L 关人物动态光与投影，T 改变动态光的左右方向作检查。T 不改变已经绘制的静态光，因此仅用于调试，不是昼夜系统。

这套接影是对二维画面的三维代理投影，不是完整 3D 家具的物理仿真。桌面深度、受光区域和半影半径均有美术标定；目前不生成完整的动态地面人物长影，也不模拟桌腿、书本对动态影子的二次遮挡。后续需要更精确的局部接影时，可增加对应表面的代理片，保持绘画本身不变。

## 连续动画

H3 服务文档来自 部署方提供的 `ASSET-GENERATION-GUIDE.md`。任务 `job_6aa81fe4_00000000`，fl2va，384×640，56 帧 / 24 fps，32 steps，seed 19720925。源视频、请求和全部原始/透明帧均保留在 `assets/animation/h3-walk-v2/`。

源帧 28–54 形成 27 帧循环（零基序号）；站立采用新版军绿色角色图。整段只使用一次固定亚像素仿射变换，不逐帧将脚底/身体吸附到整数位置，保留自然起伏。角色位移、镜头与动画更新共享渲染时钟。第 0、13 帧发出落脚事件，直接触发声音，不使用独立计时器。

朝右时允许窗光局部增亮；朝左时将动态窗光贡献置零，保留原画与缓慢空间曝光变化。桌面投影不受朝向增亮开关影响。

## 验证与参考

`docs/test-results.json`：523 项逻辑断言通过。`docs/painted/asset-validation.json`：60 项素材与真实截图检查通过，包括 14 组原像素复制、27 帧透明边界/脚底、桌面变暗、挡板和墙面不变、半影中间值。

Godot 的 [Light3D 文档](https://docs.godotengine.org/en/stable/classes/class_light3d.html)用于方向光、投影和遮挡层设置；[Spatial shader 文档](https://docs.godotengine.org/en/stable/tutorials/shaders/shader_reference/spatial_shader.html)用于材质与光照函数。Compatibility 渲染器没有方向光 PCSS，桌面因此使用显式柔化轮廓投影，避免依赖不支持的 PCSS 参数。
